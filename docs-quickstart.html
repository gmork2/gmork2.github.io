Quickstart

Set an API key and run your first chat in under a minute.

1. Set your API key

Paste your key into the API key panel and press Set key ▸, or run this in the terminal (replace the placeholder):

set_key("your-key")

2. Run your first chat

Pick a provider, then press Run ▶ (the code runs in the terminal):

resp = await client.chat.completions.create(
    model="deepseek-flash",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(resp.choices[0].message.content)
resp = await openrouter_client.chat.completions.create(
    model="openai/gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(resp.choices[0].message.content)
resp = await openai_client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(resp.choices[0].message.content)

convo.reset()
