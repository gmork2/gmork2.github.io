API Reference

The full surface of the OpenAI-compatible shim.

OpenAI(api_key=None, base_url="https://api.deepseek.com")

Creates a client. api_key is optional: if omitted it is read from os.environ["OPENAI_API_KEY"] (set by set_key() or the "Set key" button). base_url defaults to DeepSeek.

client = OpenAI(api_key="...", base_url="https://api.deepseek.com")
client.api_key   # str
client.base_url  # str
client.chat      # Chat

client.chat.completions.create(*, model, messages, stream=False, **kwargs)

Sends a chat request and returns a ChatCompletion. Extra keyword arguments (e.g. temperature, max_tokens) are forwarded to the API as-is.

resp = await client.chat.completions.create(
    model="deepseek-flash",
    messages=[{"role": "user", "content": "Hello"}],
)

Response objects

TypeAttributes
ChatCompletion.id, .model, .choices (list), .usage
Choice.index, .message, .finish_reason
ChatCompletionMessage.role, .content

make_client(provider="deepseek", api_key=None)

Returns a client for a provider name (from PROVIDERS) or a full base URL.

c = make_client("openrouter")
c = make_client("https://api.groq.com/openai/v1")

set_key(key)

Stores the API key in os.environ["OPENAI_API_KEY"] (memory only).

set_key("your-key")

Conversation(client=client, model="deepseek-flash", system=None)

A stateful helper that keeps a running messages list.

convo = Conversation(model="deepseek-flash")
convo.messages          # list
reply = await convo.say("Hello")   # str
convo.reset()           # clears messages

reset_history()

Clears the pre-built convo. Equivalent to the terminal's "↺" button.
