Installation

There is nothing to install: the interpreter is loaded and run entirely in the browser.

The page loads Pyodide (CPython compiled to WebAssembly) from a CDN and runs it inside a Web Worker. No server, package manager, or build step is required.

Requirements: a modern browser with Web Worker + WebAssembly support, served over HTTP(S). Opening the files via file:// will not work because browsers block Web Workers on the local filesystem.

Run locally

python3 -m http.server 8000
# open http://localhost:8000

Production

The site is published at https://gmork2.github.io/. The first visit downloads Pyodide (a few MB); the browser caches it afterwards.
