Providers

Any OpenAI-compatible endpoint works. These are pre-configured.

Providerbase_urlCORSNotesDocs
DeepSeekhttps://api.deepseek.comYesdefaultdocs
OpenAIhttps://api.openai.com/v1Yesdocs
OpenRouterhttps://openrouter.ai/api/v1Yesaggregates many modelsdocs
Groqhttps://api.groq.com/openai/v1Yesdocs
Ollamahttp://localhost:11434/v1localrequires Ollama running locallydocs
Tip: make_client() accepts any provider name in this table, or an arbitrary OpenAI-compatible base URL.

Use any provider

c = make_client("openrouter")                        # by name
c = make_client("https://api.groq.com/openai/v1")   # by URL
