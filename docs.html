Overview

An in-browser Python interpreter with an OpenAI-compatible LLM client, powered by Pyodide.

The terminal runs CPython (compiled to WebAssembly via Pyodide) inside a Web Worker, and exposes a client compatible with the OpenAI SDK. It works with any provider that exposes an OpenAI-compatible API — DeepSeek, OpenAI, OpenRouter, Groq, and more.

Key features

  • OpenAI-SDK-compatible API: client.chat.completions.create(...)
  • Runs entirely in the browser — no backend, no build step
  • Provider presets and make_client()
  • Live namespace inspector (the ENVIRONMENT panel)
